A Python CLI tool that fetches real-time Albion Online market prices across all cities, helping players find the cheapest buy prices and best sell opportunities without leaving their base.

# Albion Market Price Checker

A command-line tool built with Python that fetches live market 
prices from the Albion Online Data Project API.

## Features
- Search items by name instead of item codes
- Compare prices across all cities simultaneously  
- Find cheapest buy price and best sell opportunity
- Calculate potential profit between cities
- Supports all item tiers and enchantment levels

## How to use
1. Run main.py
2. Enter 1 to search for an item
3. Type item name (e.g. "bag", "sword", "bread")
4. Select cities to compare
5. Pick item from results
6. View prices and profit analysis

## Built with
- Python 3
- Requests library
- Albion Online Data Project API
